# PI Motor Accident - Letter of Claim

## Use when
- Opponent or insurer identified.
- Pre-action settlement demand.
- Liability facts sufficiently known.

## Do not use when
- Proceedings already commenced.
- Defendant identity unknown.
- Medical position too uncertain for quantum demand.

## Clauses
### CCTV preservation
Use early where incident location has likely CCTV. Do not use if stale unless lawyer wants preservation request anyway. [VERIFY]

### Special damages
Use only when receipts/pay slips/medical bills are available; otherwise insert placeholder and evidence task.
